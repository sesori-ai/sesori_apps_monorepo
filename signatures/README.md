# CLA Signature Ledger

The authoritative ledger is [`signatures/cla.json` on the `cla-signatures`
branch](https://github.com/sesori-ai/sesori_apps_monorepo/blob/cla-signatures/signatures/cla.json).

That branch is intentionally outside the `main` pull request rules so CLA
Assistant can append signatures. Do not add a ledger copy to `main`; it will
not be kept synchronized.
