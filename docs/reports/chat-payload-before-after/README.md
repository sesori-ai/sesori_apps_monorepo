# Chat payloads: before & after

Open `index.html` in a browser. It is a single-file, offline report with inline
styles and optional filtering/printing controls. You can share the HTML file
alone, or zip this folder and extract it before opening. No server or install is
required. The source links need GitHub access; they are not fetched automatically.

The five paired illustrations use synthetic examples and approximate the shared
chat widgets. **They are not screenshots or a real-harness end-to-end QA run.**
The report distinguishes verified mapper behavior, documented command-mapping
gaps, preserved behavior and recommendations that are not implemented.

five comparisons even when a screen filter is active. Essential content is also
available with JavaScript disabled. Card copy icons and child chevrons are visual
illustrations, not interactive application controls.
